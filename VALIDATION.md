## Границы проверки

- На локальном Windows Docker отсутствует; контейнерный запуск проверен в GitHub Actions.
- Откат миграции отдельно не выполнялся; upgrade и отсутствие drift проверены в CI.
- Внешние запросы OpenAI и реальные сообщения Telegram: пользовательские ключи не предоставлены.
- LLM и Telegram transport в автоматических тестах заменены mock-реализациями.
  Качество ответов реальной модели на ваших документах следует оценить после настройки ключей.

## Проверка после настройки окружения

1. Запустить Compose, seed и reindex по README; проверить `/health/ready`.
2. Задать боту вопрос о доставке, затем заведомо неподдерживаемой услуге.
3. Проверить контекст: назвать модель, затем спросить «Сколько он стоит?».
4. Нажать передачу оператору; открыть панель, взять обращение, ответить и закрыть.
5. Убедиться, что ответ доставлен в Telegram и outbox имеет статус `sent`.
6. Изменить цену через Admin API и проверить новый ответ и debug/search.
7. Проверить вопросы на своих документах и подобрать similarity threshold.
